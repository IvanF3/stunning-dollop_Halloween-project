HOW TO CHANGE A LINK
Find the link in an HTML file, for example:
<a href="history.html">History</a>

Change the text to change the name shown.
Change the address inside href="..." to choose where the link goes.
Use a filename for another page in this folder, or a full https:// address for another website.

HOW TO CHANGE PICTURES
Find an <img> line and change the address inside src="...".
Pictures from the internet need an internet connection.

HOW TO USE
Keep all seven HTML files and style.css in the same folder.
Open index.html in a web browser.
